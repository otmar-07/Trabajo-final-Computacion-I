# Trabajo-final-Computacion-I
Almacenamiento público de los datasets freMTPL2freq.csv y freMTPL2sev.csv del paquete CASdatasets, utilizados como fuente de datos en la nube para el Trabajo Final de Computación I (análisis descriptivo de frecuencia y severidad de siniestros en seguros de automóviles en Francia). Los archivos se leen directamente desde R mediante URLs raw.
